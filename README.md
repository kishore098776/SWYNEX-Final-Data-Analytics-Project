E-Commerce Sales Data Analysis & Interactive Dashboard
1. Project Overview

This project focuses on analyzing an e-commerce sales dataset containing 5,000 records to understand sales performance, customer behavior, product categories, regional performance, payment preferences, delivery performance, and revenue trends.

The project follows a complete data analytics workflow:

Data Collection → Data Cleaning → Exploratory Data Analysis → Data Visualization → Power BI Dashboard → Business Insights

2. Problem Statement

E-commerce businesses generate large amounts of transaction data, but raw data alone does not provide clear business insights.

The objective of this project is to analyze e-commerce transaction data and identify sales trends, high-performing product categories, regional performance, customer behavior, payment preferences, delivery patterns, and unusual data points using Excel and Power BI.

7. Key Business Insights

The analysis was used to identify important business insights related to:

Revenue Trends – Monthly analysis helps identify changes in revenue over time.
Product Categories – Category-level analysis shows differences in revenue contribution.
Regional Performance – Revenue varies across different regions.
Payment Preferences – Analysis of payment methods shows customer payment behavior.
Delivery Performance – Delivery-day analysis identifies common delivery durations and unusual delivery cases.
Customer Satisfaction – Customer-rating analysis provides an overview of customer feedback.
